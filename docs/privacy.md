# Privacy — Maya Extension

- **Local-first:** theme config, wallpapers, settings stay on device.
- **No telemetry:** no usage stats sent anywhere.
- **No cloud calls by default:** update source = none/manual (opt-in).
- **No personal data in logs:** only version + OS + metrics.
- **Maya project privacy rules:** DEVARAJ/ folder never touched.

## What leaves device (only if user enables)
- Update check: version number + OS/Plasma version → update server
- Nothing else. No chat, no files, no details.

## Settings
- Privacy page: "Update checks" toggle (default off)
- "Diagnostics" toggle (default off) — logs stay local anyway
- Clear local logs button

## Audit
- All network calls listed here (only update check)
- Firewall-friendly: works fully offline
